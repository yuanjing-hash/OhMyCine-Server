# 配置 PanSou 网盘与磁力搜索

在站点管理中选择 **盘搜 · 网盘与磁力**，填写自己的 PanSou 服务地址。Server 使用 PanSou API 搜索公开 TG 频道和该实例启用的插件；不会自动部署 PanSou，也不会监听 Telegram 新消息。

## 服务地址与认证

服务地址可以是 HTTP 或 HTTPS，支持 Docker 服务名、IP 和自定义端口，例如 `http://pansou:8888`。填写服务根地址，不要附加 `/api/search`。这个地址必须能从 **Server 所在容器或主机**访问；`localhost` 指向 Server 自己，不是浏览器所在电脑。使用 HTTPS 时仍校验证书。

PanSou 开启账号认证时，填写其账号与密码。Server 加密保存凭据，普通页面只返回账号名和是否已配置密码；编辑时密码留空保留原值，关闭认证会清除已存凭据。HTTP 会以明文传输认证信息，请根据实际部署网络选择地址。保存经过候选配置测试，失败时保留原配置。

## 来源和 TG 频道范围

默认搜索 **TG 频道＋PanSou 已启用插件**，也可以只选 TG 或只选插件。这里的插件是 PanSou 自己的插件，与 OhMyCine 插件管理中的开关独立。

频道输入框旁的范围选择只控制 TG：

| 频道范围 | 搜索行为 |
| --- | --- |
| 默认＋自定义 | 读取当前实例的默认频道，与填写的频道合并去重；未填写时使用实例默认频道 |
| 仅自定义 | 只搜索填写的有效公开频道；TG 参与搜索时至少填写一个 |

可填写频道名、`@频道名`或公开 `t.me` 链接。页面显示实际默认数量、自定义数量和合并后的数量，可以重新获取默认列表。规范化去重后最多 1024 个频道；超出上限或上游拒绝时明确报错，不静默丢弃多余频道。

只搜索插件时，不要求填写 TG 频道，也不依赖默认频道检测。全部来源模式下，如果 TG 默认频道读取失败，仍可保留插件结果，并显示 TG 部分未完成。频道模式不会关闭插件。

已有站点中明确填写的 TG 列表保留为“仅自定义”。缺少新来源或类型设置的旧配置，采用全部来源、全部已启用插件和自动类型；原服务地址、账号和频道不会被默认值覆盖。

## 自动选择显示类型

默认根据当前用户有权使用、已启用且配置完成的网盘分享接收器筛选结果，同时查询磁力链接。仅添加连接、完成登录或拥有一个可读媒体库，不代表已经配置分享接收器。接收器还需要有效的数据源、凭据和接收目录；夸克接收目录必须已有对应播放与管理授权的共同目录证明。普通用户无需“读取连接”管理权限。

| 当前用户可用的网盘配置 | 默认结果类型 |
| --- | --- |
| 无 | 磁力 |
| 115 | 115、磁力 |
| 夸克 | 夸克、磁力 |
| 115 和夸克 | 115、夸克、磁力 |

自动判断只读取保存的配置，不在每次搜索时请求网盘、刷新授权或重新验证目录。一次临时连接失败、限速或同账号凭据轮换不会让已配置类型消失。用户也可以手动选择类型或查看全部类型；缺少可用接收器时，结果保留真实网盘类型，并说明暂时不能入库。其他已识别的网盘链接可按权限查看或复制，不能把其他网盘或电驴链接当作磁力提交。

“TG／插件”表示来源，“115／夸克／磁力”表示结果类型，两者独立。结果卡片保留频道或插件名称；插件返回的分享不会因为没有 TG 频道而被过滤。多个来源找到同一资源时会归并并保留来源信息。

## 入库和订阅

搜索结果会自动分析分享里的真实视频文件，显示作品、季数和实际集数。BT/PT 继续按资源标题识别；分享帖标题只提供线索，不能证明目录里有整个范围。例如帖子写“1–14”，目录只有 E11、E13、E14 时，显示“11、13–14”，不会补上 E12。多个作品、多个季分别显示，同集多个格式不重复计算集数。ZIP、字幕和样片不会成为独立剧集。

自动分析按配置顺序选择当前用户有权使用的同网盘接收器；人工预览仍使用明确选择的接收器。没有接收器、权限不足或目录未能完整读取时，会说明尚未核实，不能把标题范围显示为实际文件。完整目录已读取但作品身份未确认时，保留实际文件集数和待确认状态。订阅复用同一分析，只选择已验证作品、指定季和已确定缺失的实际视频叶文件。

| 资源类型 | 处理方式 |
| --- | --- |
| 115 分享 | 推荐有权限且路由可用的 115 分享接收器 |
| 夸克分享 | 推荐夸克分享转存下载器；预览真实目录并转存选中文件 |
| 公共磁力 | 沿现有 BT 下载器顺序和目标库可达性选择 |
| PT | 仍只走 qBittorrent；PanSou 扩展不会放宽 PT 路由 |
| 尚不支持的网盘或链接类型 | 可以查看受控链接，不能创建入库任务 |

**夸克下载器仅提供分享转存，未提供云离线下载。** 它不会被推荐用于磁力或 PT。本地或 qBittorrent 下载完成后上传到夸克，是独立的文件上传流程。

推荐、预览、订阅和最终提交依据每条结果的真实来源；切换目标媒体库会重新推荐。分享转存失败不会自动换第二个接收器。公共 BT 只有确认未创建任务的明确拒绝才允许尝试下一个兼容下载器，超时或结果不明时停止，避免重复任务。

## 搜索进度、翻页和重试

页面显示请求阶段、耗时、已收到的条数，以及失败或未完成的部分。PanSou 一次返回 JSON，并不一定提供内部每个插件的实时进度；界面不会凭计时制造完成百分比。

同一次搜索的翻页读取固定结果快照，点击上一页回到第一页也继续使用该快照，不会每翻一页重新请求全部插件。重试或刷新建立新的搜索代际。快照到期、服务重启、搜索条件或用户接收权限变化，以及接收器停用、账号或目录证明变化时需要重新搜索；临时健康状态和夸克同账号自动凭据轮换不影响快照。达到返回数量、大小等边界时会标记截断，不能把有限结果冒充全部完成。后续失败保留此前已收到的有效结果。

旧版 Player 没有声明混合结果能力时，仅收到其可识别的 PanSou 115 分享结果；升级后才显示夸克和磁力等混合类型。新版 Player 连接旧 Server 时继续使用原有功能，新增选项根据 Server 能力显示。

## OhMyCine 插件停用后的站点

停用 OhMyCine 的挂了.com 插件后，其派生站点保留配置和历史，显示“插件已停用”，不再作为可搜索或订阅来源。旧结果会显示不可用，后端也会拒绝新的提交。重新启用恢复原配置，不会擅自开启用户原先手动关闭的站点或连接。停用前已经接收的任务按原路线继续。

PanSou 内部的 `gying` 来源仍由 PanSou 管理，因此可能继续返回同一站点的资源。查看结果上的来源标签即可区分两条来源。

## 接口合同

现有 `POST /api/v1/discovery/torrent-results/recognize` 和 `POST /api/v1/discovery/share-preview`（以及对应 `/api/v1/player/discovery/...`）响应新增可选 `share_analysis`，不增加轮询接口。它包含 `status=complete|unavailable`、`complete`、`groups`、`video_count`、`ignored_count`、`unresolved_count`、安全 `message/error_code`、`checked_at/expires_at` 和 `downloader_id`。每组提供 `title`、`media_type`、可选 `tmdb_id/year/season/poster_url`、精确排序去重的 `episodes` 数组、`video_count`、`status=matched|unrecognized` 和可选身份错误。空分组/集数使用 `[]`。读取失败时 `complete=false`、`groups=[]`；识别元数据失败不抹掉已经完整读取的文件事实。

分析沿用完整目录的 200 目录、15 层、2,000 条目边界；单次请求最多 45 秒，元数据识别另有最多 8 组及 10 秒子预算，公开摘要最多 32 组、每组最多 2,000 个实际集数。超出识别预算的文件计入未确认数量。短期复用最长五分钟并绑定当前用户权限、真实分享来源和接收配置；重复结果不会刷新旧证据的到期时间。人工重新预览读取最新目录。配置、权限或人工身份变化会阻止旧结果继续使用。摘要没有提供商文件 ID、URL、提取码或可提交的文件选择令牌。

兼容保存的站点类型仍为 `kind=pansou_tg`、`site_type=cloud_share`。这个分类不再决定每条结果的下载路线。`cloud_config`增加：

```json
{
  "source_scope": "all",
  "channel_mode": "defaults_plus_custom",
  "channels": [],
  "plugins": [],
  "type_policy": "auto",
  "cloud_types": [],
  "auth_enabled": false
}
```

`source_scope`支持`all|tg|plugin`；`channel_mode`支持`custom_only|defaults_plus_custom`；`type_policy`支持`auto|all|manual`。空插件列表表示所连实例的全部已启用插件。旧`provider`字段仅用于兼容读取，不再限制查询只能返回一种网盘。

支持混合结果的客户端在现有搜索接口声明`client_capabilities=mixed_discovery_v1`。请求可覆盖`type_policy`和`cloud_types`，后续页携带`snapshot_id`；首屏显式刷新使用`refresh=true`。

结果保留不透明短期`token`，增加`result_type`、`origins`、`acquisition_available`及`acquisition_reason`。混合结果中的 115／夸克分享只有在当前用户存在配置完成的对应接收器时才标记可获取；下载器摘要的`capabilities.share_receive`使用相同的本地配置与权限判断。可获取不保证当前云端健康或一定存在可达目标库，最终仍以路由推荐及提交校验为准。旧 Server 缺少这些新增字段时，客户端保留旧行为。分组返回`snapshot_id`、`snapshot_expires_at`、`partial`、`truncated`、`completion`、`warnings`和范围信息；缺少上游全量完成证据时不能标作`complete`。

管理端通过`GET /api/v1/sites/:id/pansou-scope`读取已保存站点范围，通过`POST /api/v1/sites/pansou-scope`检测尚未保存的配置。强制刷新时，GET 使用查询参数 `refresh=true`，POST 使用 JSON 请求体中的 `refresh: true`。读取保存的认证信息必须绑定原站点、修订和相同服务地址，不得把已有密码发送到另一个地址。

普通结果列表不返回资源 URL 或提取码。显式查看链接使用 `POST /api/v1/discovery/results/link`（Server 网页）或 `POST /api/v1/player/discovery/results/link`（Player），请求体为 `{"result_token":"不透明结果令牌"}`。接口重新检查用户权限、站点修订、有效状态和令牌期限，并以 `Cache-Control: no-store` 返回受控链接；返回值不能写入持久客户端缓存。搜索结果不是任意 URL 下载入口。

更多夸克功能见[使用夸克网盘](../operations/quark-native.md)。
