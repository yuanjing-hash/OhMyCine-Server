# 使用夸克网盘

夸克连接将播放和文件管理放在同一处管理。媒体文件保留在夸克，Server 负责目录、识别、任务、签名地址和本地 STRM 等产物。播放使用 TV 原文件 302；客户端从夸克读取视频，不通过 Server 或 Node 中转播放。

本文对应当前实现。代码测试通过不代表所有真实设备已完成验收；末尾列出仍需单独验证的项目。

## 添加连接和媒体库

1. 在连接管理中新建夸克连接，完成播放授权和文件管理授权。TV 与 Agent 是两套独立授权；按页面当前步骤完成即可，不需要先提供 Cookie，也不要求 Web 作为第三次登录。
2. 选择用于本系统管理的根目录并完成共同空间验证。Server 会创建极小验证文件，由播放接口独立读取，确认两套授权能访问同一根范围；保存证明后，再清理本次拥有的精确验证文件。更换账号或根目录后需要重新验证。
3. 使用该连接建立 Storage，再选择媒体库范围。需要 STRM 时，配置 Server 可写的本地投影目录及客户端可达的 Server 外部地址。
4. 等待首次目录覆盖。已确认内容可以陆续显示；只有范围覆盖和本地发布都结束才显示完成。

正常 TV 兑换和续期使用 `https://api.extscreen.com/quarkdrive/token`。它会接收 TV 授权码或刷新令牌，并返回 TV 访问令牌；这是一项第三方服务。Agent 和已有 Web 凭据不发送给它。令牌在 Server 加密保存，不需要复制到 Player。

连接显示播放、文件管理与分享转存等能力状态。播放授权可用不代表管理授权也可用；管理授权已完成但共同空间尚未证明时，写入能力仍不可用。凭据同身份续期由系统处理，不要求每次重新扫码。

上传结果不明时，再次验证会继续核对同一个随机文件，不新建第二份。已保存的证明不会因验证文件清理等待而失效。页面出现“验证文件清理尚未确认”时，可以先完成数据源创建，再用“重新核对验证文件”继续处理；不需要重新选择目录或登录。确认结果仅表示原验证文件已不在所选目录中，不代表永久清除或回收站验收；清理不会按文件名前缀删除其他文件。

重启后，系统会按原上传任务读取完整分页；如果提供方明确返回任务完成及文件身份，就继续核对原输出，不再上传或重复结束任务。旧的结果不明记录仍需要这些证据，不能保证每条旧记录都能自动恢复。不要删除连接配置、清空操作记录或重新扫码来绕过它；这会丢失核对原操作所需的信息。只有能证明请求尚未发出的本地失败，才允许继续同一次原始意图。提供方返回的 HTTP 和 HTTPS 上传地址均可使用，对象上传不跟随重定向。

STRM 内容是 OhMyCine 的签名地址。不要把夸克临时直链手动写成永久 STRM；链接失效应由播放解析重新取得，不能依赖批量重写 STRM 修复。签名到期、密钥轮换仍按已有规则处理。

## 文件如何自动出现

直接把视频放入最终媒体库后，Server 通过目录巡检发现它，识别并生成本地产物。默认不会为了索引而移动或重命名云文件。

如果希望放进去后自动整理，需要另配接收目录并启用自动接管，绑定目标库。接收根与最终库根不能重叠。候选需要两次完整稳定观察及至少 60 秒静默期；本系统 `omc-*` 任务目录和验证文件不会再次被接管。

本系统转存或上传成功后会立即处理已确认目标，不等下一次巡检。分享预览展示真实目录，只转存选中文件；文件保存后，后续入库依赖保存后的目标文件，不依赖发布者继续保留分享。

外部更新不是即时推送。接收根目标约 1 分钟、近期变化目录约 2 分钟、普通库根约 15 分钟；冷目录轮转目标是 24 小时。大库、分页多或被限流时会延后，以媒体库显示的覆盖进度和下一次重试时间为准。频繁点击同步不会绕开账号冷却。

## 删除和恢复

一次未找到不会立刻下架。系统需要两轮相隔至少 10 分钟的完整复查，并排除文件只是移动到库内另一处；授权失效、分页异常或未完成写入期间不会据此删除目录记录。

确认移出范围后，清理的是本系统持有的媒体目录与系统生成的本地产物，不会据此删除夸克文件。恢复原文件后，系统尽量依据稳定资源身份恢复媒体记录、人工匹配和观看历史，而不是按同名文件猜测。

## 整理、上传与跨盘

当前已接通同盘移动/重命名、目录创建、选择分享转存和上传。普通云端复制、回收及恢复、永久清理、夸克云离线未开放。

添加下载器时选择夸克分享转存接收器，并设置对应账号、接收目录和执行位置。它只接收夸克分享，不接收磁力或 PT。qBittorrent 下载到本地后上传到夸克目的库，仍由独立的传输任务完成，不属于夸克云离线下载。

目标重名可选择跳过或改名。当前夸克不提供依赖回收能力的覆盖删除。已完成入库后，云端接收目录及剩余文件可能保留，任务会明确说明原因；不应把“保留源文件”误认为入库失败。

已完成任务的“重新整理”支持版本化夸克媒体库，先展示预览，再按确认的计划移动或改名。云端结果尚未确认时保留原任务；遇到授权失效或结果不明，可在任务中按提示处理后点击“重新核对”。该按钮继续核对原操作，不创建第二次移动或改名。核对期间，相关目录不会因为暂时缺项被巡检下架。此入口用于已管理任务的输出，不是对全库任意文件执行批量整理。

本地或 qBittorrent 文件可以上传到夸克。没有可比较的可信提供方摘要时，会完整读回原文件比较 SHA256，因此确认阶段会增加下载流量和耗时。正常新建的跨接口上传保留首次身份映射和最终交付核验两遍完整读取，省去中间重复的一遍；恢复核对或异常重试可能增加读取，不能按一次下载估算所有任务的确认成本。文件列表中出现同名文件并不等于任务已完成。

从夸克复制到另一数据源时，先进入受管暂存并计算摘要，再完成目标写入。当前缺少已验证回收能力，要求删除夸克云源的跨盘移动不可用；使用保留源文件的复制流程。任务重试会核对已有操作，不自动重复转存或改用另一接口。

选择远程 Node 前，需要该 Node 支持相应夸克读取/转存/上传及摘要合同。能力不足时先升级 Node；Server 不会把已选远程任务悄悄改成由自己传输。播放仍固定使用 TV 302，与文件搬运的节点选择无关。

## 常见状态

| 状态或现象 | 含义与处理 |
| --- | --- |
| 播放已授权，管理未就绪 | 完成 Agent 管理授权和共同空间验证 |
| 等待授权/设备数量限制 | 查看连接的明确错误；按夸克账号提示处理设备或授权，再继续原流程 |
| 等待限流重试 | 账号在共同冷却中；查看重试时间，反复提交不能解除限制 |
| 已读取部分内容，仍在同步 | 当前目录或整个范围尚未完成；已确认内容可展示，缺项不会因此删除 |
| 待确认缺失 | 文件可能被移动或暂时不可见，系统正在进行第二轮及范围复查 |
| 文件已保存，仍在确认 | 正在核对上游结果、目标身份或完整内容，不能直接当作失败重新提交 |
| 入库完成，刷新失败 | 媒体已入库，重试通知或产物步骤即可，不应重做转存/上传 |
| 原文件链接不可用 | 播放解析失败；检查播放授权、文件访问和账号条件，不会自动改为转码或代理 |
| 已开始播放但持续低速缓冲 | 地址可读与持续播放速度是两项检查。记录文件大小、发生时间和持续读取速度，区分播放器显示与实际网络吞吐；不要只因低速反复扫码或重建连接 |

排查时提供任务 ID、阶段、错误代码和发生时间即可。不要公开 Cookie、刷新令牌、分享私密凭证或完整临时播放 URL。不要用外部 SQLite 工具直接打开运行中 Server 的主数据库进行修复。

共同空间验证的日志会保留实际上传阶段，例如 `upload_prepare`、`upload_part_prepare`、`upload_part_recovery`、`upload_task_query` 或 `upload_finish_response`，以及可用的 HTTP 状态和提供方错误码。安全状态字段还能区分“已有原任务但未完成”“已完成且有原输出”“本地尚未发出请求”等分支；它们不包含上游任务标识或凭据。仅看到 `cloud_mutation_result_unknown` 不能据此认定上传失败，也不需要重新扫描媒体库。

## 尚需真实环境验收

截至 2026-10-22，同一原文件的开放范围读取曾在独立 HTTP 客户端与 Windows Player 桥接中复现约 100 KiB/s，而有界读取达到 MiB/s。Windows Player 已采用 8 MiB 有界读取，原生桥接实测通过，用户也已确认实际播放和反复拖动正常。这个结论限于已测样本、平台和环境，不是夸克公布的固定限速规则，也不代表所有播放器均已验收。不能据低速推断未开会员，或据会员状态保证 TV 路由吞吐。

已完成的 Windows Player 播放与拖动无需重复作为开发前置条件；Emby、其他播放器、音轨和外挂字幕等专项保留独立验收状态。真实多分片上传已有小样本完整读回校验，GB 级大小边界使用离线检查，实际 Node 云传输采用最小样本；接口和模拟回归不能代替真实运行结果。Web 专属复制/回收/恢复及云离线未完成验收前保持不可用，不影响已具备的独立功能。此实现不自动发布或部署到运行中的系统。
