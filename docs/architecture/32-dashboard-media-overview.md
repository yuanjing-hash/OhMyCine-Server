# 仪表盘媒体、任务与容量

仪表盘读取已有任务和有效媒体目录，不在GET中测试云盘、搜索站点、扫描媒体库或触发下载。订阅近期日程复用订阅日历的本地读取接口，日期与状态不再维护第二套算法。

## 任务与媒体

`GET /api/v1/dashboard/activity`要求认证、`dashboard.read`，响应`Cache-Control: no-store`。每个分区独立为`ok`或`unavailable`，保持空数组和安全错误码，单项故障不盖住其他内容：

- `active_tasks`：仅正在运行的任务；显示实际获权名称、任务类型、真实进度和任务中心`job_id`详情入口。没有运行任务显示“暂无正在执行的任务”。
- `waiting_tasks`：排队、等待重试、暂停，最多8条，并提供更多入口。
- `attention_tasks`：失败或等待用户处理，最多8条；历史完成记录不属于当前活动任务。
- `recently_added`：通过已有有效目录、可读媒体库和`added_at`排序，返回最多8部作品，不加载观看历史，也不使用任务完成时间代替入库时间。
- `capacities`：仅保存的容量测量，不访问云端；最多50个数据源，超出时标记`has_more`。

任务复用QueueService的账号、资源和安全文本投影；受限库/下载器/站点不会通过首页恢复私密任务标题。媒体图片和跳转使用浏览器目录DTO，不返回提供方文件标识、物理路径或播放凭据。

现有`GET /api/v1/dashboard`保留管理字段。`users/active_users`、`roles`、`audit_events`分别要求`users.read`、`roles.read`、`audit.read`；没有对应权限时为null。`dashboard.read`不授予这些管理数据的读取权限。原operations接口保留，活动统计排除终态历史。

## 容量合同

容量是驱动可选的`cloud.QuotaReader`能力。当前115通过既有账号空间接口读取，不执行目录扫描或完整连接检测；本地文件系统复用现有容量检测。当前夸克TV/Agent组合没有经过验证的容量合同，明确返回“当前授权未提供容量”，不猜测上游协议、不要求为首页另扫一次码。

`POST /api/v1/storages/{id}/capacity`要求认证、CSRF、`storages.read`和`storages.test`，响应不缓存。该操作只更新容量测量，独立于目录可读性测试，不改变下载、移动、转存、根证明或任务状态。

测量开始前原子登记原数据源范围及尝试时间；同范围一分钟冷却。提供方请求使用20秒上下文及现有账号限流；网络I/O不在数据库事务或写入许可内。结束通过短写入事务核对同一根、连接epoch、连接身份/配置revision和尝试时间，迟到旧结果不能挂到新来源。

持久字段区分最近尝试时间与最近成功采样时间。失败保留同范围的上次成功值，不更新成功时间；换根/换账号范围不匹配时不返回旧容量。完整状态包括尚未检测、更新中、已更新、已过期、失败、能力未提供和已停用。重启留下的更新中状态在有限期限后显示未完成，可在冷却后重试。

首页刷新、任务事件和15秒轮询只更新本地投影。当前没有新增自动容量轮询；管理员通过“更新容量”明确发起测量。此边界防止普通首页访问被放大为云端请求。

## 页面与恢复

主区域为正在执行、需要关注、未来七天更新和最近入库；容量、连接、计划与快捷入口放在次要区域。无研发占位卡、数据负责人标签或虚构流水线健康。容量和速率使用自适应字节单位。

请求使用独立latest-request所有权。换账号、权限变化和卸载会取消并清除受保护数据；旧响应不能写入新账号。普通短暂失败保留仍获权的成功快照并说明过期；401/403清除对应分区。隐藏页面停止任务事件连接与轮询。

显式容量更新成功时，撤销此前仪表盘读取的发布权，再合并已确认采样；晚到的旧读取不能覆盖刚测得的容量或留下永久加载状态。私密采样字段只由测量更新写入，普通数据源创建不注入样本，也不使升级前的创建流程依赖新增容量列。

本地行为测试覆盖实际任务名称、零运行任务、完整目录读取、独立分区故障、普通用户管理字段、显式容量更新、失败保旧、来源变化、迟到请求和权限切换。构建与本地测试不等于当前部署、真实115账号、实际浏览器或设备验收。
